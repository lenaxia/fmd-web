## Implementation notes

- **State choice (documented in web/README.md): @tanstack/react-query**
  owns all server state (queries, mutations, cache patching from WS
  events, `resync` invalidation); local UI state stays in
  useState/useRef; routing is a hand-rolled hash router (4 pages +
  query params). Vite WITHOUT the React plugin — esbuild applies
  `jsx: react-jsx` from tsconfig.
- **D19 state machine** (`src/state/ws-backfill.ts`): transport-agnostic
  `WsBackfillController` (WebSocket factory + timer injection) so tests
  drive a mock socket with captured timers; the hook
  (`src/state/use-jobs-feed.ts`) binds it to React Query — events patch
  every `['jobs', …]` infinite-query cache (each PAGE mapped through
  `patchJobsPage`, replace-by-id or prepend), `resync` invalidates.
  Protocol documented in `ws-protocol.ts` (hello carries lastEventId;
  events are job snapshots; resync = window outside the 1000-event/
  15-min ring buffer → refetch + cursor reset).
- **§5.1 combobox INDEX semantics**: `OptionsEditor` renders labels;
  drafts keep the rendered index as a string; `collectOptionValues`
  round-trips to the stored INTEGER index (checkbox→boolean, edit→string,
  spinedit→integer; out-of-range/NaN dropped). Documented API limit: the
  §10 read model exposes descriptors + defaultValue only (no stored
  values), so drafts seed from defaultValue.
- **D20 empty states**: Browse without a catalog, Downloads without
  jobs, and Settings with an empty registry all render explicit guidance
  with a runnable bootstrap action (module sync) whose progress + result
  summary surface inline (D20 auto-trigger documented in the copy).
- **E2E gotchas fixed** (documented for the next worker): glob
  `**/api/**` matches the SPA's own `/src/api/*` modules — API mocks
  must be origin-anchored regexes; Playwright matches routes in reverse
  registration order (register the catch-all FIRST); `page.getByLabel`
  (not getByLabelText); infinite-query caches hold `InfiniteData` —
  cache patches must map `pages`.
- Root config touched additively only: `vitest.config.ts` include gains
  `web/test/**/*.test.tsx` (web tests already in the root run); eslint
  scope gains tsx. Root `package.json`/`package-lock.json` web-dep churn
  is left uncommitted per the in-flight convention (API workers' server
  deps are in the same uncommitted lock); `npm install` materializes
  `web/package.json` (react, react-dom, @tanstack/react-query,
  openapi-fetch; dev: vite, openapi-typescript, @playwright/test,
  testing-library, jsdom).
- Chromium for Playwright is a pinned download
  (`npx playwright install chromium`, one-time, off-CDN at test time).
